# Food InWest

Premium, flersidig webbprototyp för Food InWest.

## Nuvarande sidor

- Startsida
- Varumärken
- Produkter med sökning och filter
- Inspiration
- Om oss
- Kontakt
- Kundportal (visuellt förhandsläge)

## Designprinciper

- Djup skogsgrön grund med dämpat guld och varmvit typografi.
- Tunna linjer delar upp sektioner och bildboxar.
- Produktbilder tonas in med CSS-masker; inga raka skarvar mot bakgrunden.
- Originaletiketter och produktvarumärken får inte tas bort eller genereras om.
- Food InWest-logotypen används med guldlövet.

## Teknik

Versionen är avsiktligt bygglös: semantisk HTML, CSS och JavaScript. Den kan senare migreras till React med TanStack Router och TanStack Query när produkt-API, kundinloggning, priser, lagerstatus och orderläggning ansluts.
