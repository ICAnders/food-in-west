# Lovable handoff

Använd detta repository som visuell och funktionell grund. Lovable ska främst användas som UX- och gränssnittsverktyg.

## Får förbättras

- Responsivitet och tillgänglighet.
- Komponentstruktur och återanvändning.
- Mikrointeraktioner, hover, fokus och mobilnavigation.
- Informationsarkitektur på undersidorna.
- React/Vite-migrering och vid behov TanStack Router.
- TanStack Query först när ett verkligt API kopplas in.

## Får inte ändras

- Ersätt inte hero- eller produktbilderna med AI-genererade bilder.
- Ta inte bort, skriv om eller förvräng Luscombe, Fairfields Farm, Gran Luchito, Stokes eller Plain & Simple.
- Ta inte bort guldlövet från Food InWest-logotypen.
- Återgå inte till beige standardkort eller generisk SaaS-design.
- Ta inte bort de tunna guldfärgade linjerna och den bildrika boxindelningen.
- Skapa inte en enda lång sida; behåll separata routes.

## Hero

Produkter ska vara små och eleganta med mycket mörkgrön luft. Bildlagret ska tonas in med CSS mask-image/gradient så att ingen rak skarv syns mellan foto och bakgrund.
